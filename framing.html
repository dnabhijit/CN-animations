Framing Techniques

Module 2.1 — Data Link Layer · How a receiver knows where one frame ends and the next begins. Step through each method below.

Bit-oriented protocols (like HDLC) mark frame boundaries with the flag pattern 01111110. To stop that pattern from appearing by accident inside real data, the sender inserts a 0 immediately after every run of five consecutive 1s. The receiver reverses this on the way in.

Byte-oriented protocols mark a frame with flag bytes (here shown as FLAG). If that exact byte value happens to occur inside the data, the sender inserts an ESC (escape) byte just before it, so the receiver knows to treat it as data, not a delimiter.
